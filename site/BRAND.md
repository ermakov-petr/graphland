# GraphLand visual reference

All four GraphLand pages follow the shared visual system of [Yandex Research](https://research.yandex.com/). Their white scientific introductions follow [Publications](https://research.yandex.com/publications); the same header, fonts and responsive container were checked against [About](https://research.yandex.com/about). These are measurements of the public site captured on 2026-10-08, rather than a claim of official design-system certification. A fresh reference capture on 2026-10-26 confirmed that both original logo SVG geometries, all five font files and the reference stylesheets remain unchanged. Publications retains the 48px / 40px / 30px heading scale used here; the larger homepage heading belongs to its distinct landing-page composition.

Interface text and numeric tables use YS Text; descriptive editorial text uses Merriweather Light. Heading weight is 500, regular interface text is 400, serif text is 300. H1 tracking is −0.008em on desktop and −0.004em on mobile. All four pages share one intro and typography scale: H1 is 48/48px, 40/40px, then 30/32.4px; content H2 is 32px / 24px / 24px; H3 is 24px / 18px / 18px. Editorial lead and body copy use 22px / 17px / 15px at line-height 1.5. These heading and prose roles follow the reference's inner-page and rich-text styles. Buttons have a 30px radius, with 52px / 18px type above 1600px and approximately 40px / 14px type below. The Submit accent is #fed42b, with #f5c400 on hover.

The five WOFF2 files and three SVG drawings are hosted locally under `assets/brand/`. Their source URLs, captured build and SHA-256 hashes are recorded in [provenance.json](assets/brand/provenance.json). HTML and CSS use relative URLs, including when served under `/graphland/`. Three critical font faces are preloaded; the remaining faces load on demand. Font declarations are paired with actual files for every used weight.

Content is specific to GraphLand: the comparison table, protocol explanations, filters and review disclosures retain their scientific meaning. Per the 2026-10-26 project brief, the header contains only the original two-part SVG logo: the entire wordmark links to the canonical HTTPS Yandex Research home page. Research section links, header search and the mobile navigation menu are omitted. The original logo geometry, responsive dimensions and header spacing are retained. Search placeholders and footer hover retain readable contrast; the reference's low-contrast placeholder and gray-on-black hover were not copied.

Run `python -m unittest discover -s tests/leaderboard -v` for build/data/frontend checks and `python -m unittest discover -s tests/browser -v` with the pinned Playwright requirements and Chromium installed for interaction/brand checks. Brand tests verify served font bytes, actual glyph fonts, SVG geometry, responsive boundaries and the single external logo link. A deliberate font 404 establishes that the glyph test detects fallback rather than merely reading the CSS font-family. Dialog history includes a deterministic delayed-close focus regression.

The project has four native pages with its own navigation beneath the Research header. The original logo remains the only header control. Project navigation follows Research's regular 400-weight text, 20px / 16px scale, 32px desktop gaps and gray active/hover text without a bold or underlined active state. Mobile uses a 16px horizontal strip with 24px gaps as a deliberate adaptation instead of the reference's fullscreen menu; the active section is kept horizontally visible without moving the page vertically. All four routes use the same page-intro, title, lead and content spacing. The former large illustrated Leaderboard hero is removed. Dataset documentation and loading examples follow the supplied GraphLand brief; OGB informs information architecture only. Python blocks use semantic syntax colors distinct from brand accents.

The common system extends through the complete page, not only its intro. Leaderboard explanations, the result legend, protocol and submission steps use white editorial sections on the same shell and spacing scale as dataset documentation. Their descriptions share the Merriweather prose scale; utility labels and tables use YS Text. Both filter groups use the same flat text-tab treatment with a thin selected underline. The catalog and leaderboard share header fill, color and type size. Page actions use one outlined rounded button component; Submit results is the single yellow action. Protocol and citation disclosures share their separators and summary scale.
