Use GraphLand

Getting Started

Use PyTorch Geometric to download GraphLand datasets and apply the provided preprocessing. Raw dataset files are also available from Zenodo and Kaggle; the repository contains the reference experiments.

Choose a dataset name and one of RL, RH, TH, or THI. The examples below inspect the returned graphs and split masks without requiring a model or training loop. The first run downloads and processes the selected dataset; later runs reuse the local cache.

Install the loader

Use a supported Python version and install PyTorch for your platform, following the official PyG installation guide. Current stable documentation supports Python 3.10–3.14. GraphLand preprocessing also imports pandas, scikit-learn, and PyYAML. Install PyTorch · PyG installation guide

python -m pip install torch-geometric pandas scikit-learn PyYAML

Load one graph: RL, RH, or TH

The transductive settings return one Data object with train_mask, val_mask, and test_mask. The example loads artnet-views using RL.

from torch_geometric.datasets import GraphLandDataset

dataset = GraphLandDataset(
    root="data/graphland",
    name="artnet-views",
    split="RL",  # RH and TH also return one graph.
    regression_targets_transform=None,  # Keep regression targets in their original units.
)
data = dataset[0]

print(data)
print("Feature matrix:", tuple(data.x.shape))
for split_name in ("train", "val", "test"):
    mask = data[f"{split_name}_mask"]
    print(split_name, "labeled nodes:", int(mask.sum().item()))

Load three snapshots: THI

THI returns train, validation, and test snapshots in that order. Each graph has its own mask of labeled nodes for the corresponding stage.

from torch_geometric.datasets import GraphLandDataset

dataset = GraphLandDataset(
    root="data/graphland",
    name="artnet-views",
    split="THI",
    regression_targets_transform=None,
)
train_data, val_data, test_data = dataset

for graph in (train_data, val_data, test_data):
    # THI uses one `mask` per snapshot, not train_mask/val_mask/test_mask.
    print(
        graph["snapshot"],
        "nodes:", graph.num_nodes,
        "edges:", graph.num_edges,
        "labeled nodes:", int(graph.mask.sum().item()),
    )

Evaluation notes

  • TH and THI are unavailable for city-reviews, city-roads-M, city-roads-L, and web-traffic.
  • THI is selected with split="THI"; there is no separate snapshot constructor argument. Unpack the three returned Data objects as train, validation, and test.
  • Use each THI graph’s mask for supervised nodes. Access the stored snapshot label as graph["snapshot"] to avoid confusion with the Data.snapshot method.
  • The examples set regression_targets_transform=None to retain target units. They inspect data only and do not train or report a benchmark score.
  • Fit models and learned preprocessing on training data; use validation data for model selection, and reserve test labels for final evaluation.
  • By default, PyG converts directed graphs to undirected graphs. Set to_undirected=False explicitly when your experiment requires the original directionality, and report this choice.
