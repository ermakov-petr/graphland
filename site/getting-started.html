Getting Started

Use PyTorch Geometric to download GraphLand datasets and apply the provided preprocessing. Raw dataset files are also available from Zenodo and Kaggle; the repository contains the reference experiments.

Choose a dataset name and one of the available experimental settings: RL, RH, TH, or THI. Both examples train a small graph convolutional network on artnet-views using mean squared error on the preprocessed targets. They select a checkpoint by validation R² and evaluate it once on the test split. The first run downloads and processes the selected dataset; later runs reuse the local cache.

Install the loader

Use a supported Python version and install PyTorch and PyTorch Geometric (PyG) for your platform, following the official PyG installation guide. Current stable documentation supports Python 3.10–3.14. The GraphLand loader requires PyG 2.8 or later. GraphLand preprocessing also imports pandas, scikit-learn, and PyYAML. Transductive setting (RL, RH, or TH): load a single graph

The transductive settings return one Data object with train_mask, val_mask, and test_mask. The example loads artnet-views using the RL setting.

from copy import deepcopy

from sklearn.metrics import r2_score
from torch import no_grad
from torch.nn.functional import mse_loss
from torch.optim import Adam
from torch_geometric.datasets import GraphLandDataset
from torch_geometric.nn.models import GCN

dataset = GraphLandDataset(
    root="data/graphland",
    name="artnet-views",
    split="RL",  # RH and TH also return one graph.
)
data = dataset[0]

model = GCN(data.num_features, hidden_channels=32, num_layers=2, out_channels=1)
optimizer = Adam(model.parameters(), lr=0.01)
best_val_r2 = -float("inf")
best_state = deepcopy(model.state_dict())

for epoch in range(10):
    # Use the same graph at every stage and select labels by split.
    model.train()
    optimizer.zero_grad()
    pred = model(data.x, data.edge_index).squeeze(-1)
    loss = mse_loss(pred[data.train_mask], data.y[data.train_mask])
    loss.backward()
    optimizer.step()

    model.eval()
    with no_grad():
        pred = model(data.x, data.edge_index).squeeze(-1)
        val_r2 = r2_score(data.y[data.val_mask], pred[data.val_mask])
    if val_r2 > best_val_r2:
        best_val_r2 = val_r2
        best_state = deepcopy(model.state_dict())

# Evaluate once on test labels, using the best validation checkpoint.
model.load_state_dict(best_state)
with no_grad():
    pred = model(data.x, data.edge_index).squeeze(-1)
    test_r2 = r2_score(data.y[data.test_mask], pred[data.test_mask])

print(f"Best validation R²: {best_val_r2:.4f}")
print(f"Test R²: {test_r2:.4f}")

Inductive setting (THI): load three snapshots of a dynamically evolving graph

THI returns train, validation, and test snapshots in that order. Each graph has its own mask of labeled nodes used for the corresponding stage (training, validation, or testing).

from copy import deepcopy

from sklearn.metrics import r2_score
from torch import no_grad
from torch.nn.functional import mse_loss
from torch.optim import Adam
from torch_geometric.datasets import GraphLandDataset
from torch_geometric.nn.models import GCN

dataset = GraphLandDataset(
    root="data/graphland",
    name="artnet-views",
    split="THI",
)
train_data, val_data, test_data = dataset

model = GCN(train_data.num_features, hidden_channels=32, num_layers=2, out_channels=1)
optimizer = Adam(model.parameters(), lr=0.01)
best_val_r2 = -float("inf")
best_state = deepcopy(model.state_dict())

for epoch in range(10):
    # Train on the training snapshot and its labeled nodes.
    model.train()
    optimizer.zero_grad()
    pred = model(train_data.x, train_data.edge_index).squeeze(-1)
    loss = mse_loss(pred[train_data.mask], train_data.y[train_data.mask])
    loss.backward()
    optimizer.step()

    # Validate on the later snapshot, using that snapshot's mask.
    model.eval()
    with no_grad():
        pred = model(val_data.x, val_data.edge_index).squeeze(-1)
        val_r2 = r2_score(val_data.y[val_data.mask], pred[val_data.mask])
    if val_r2 > best_val_r2:
        best_val_r2 = val_r2
        best_state = deepcopy(model.state_dict())

# Use the test snapshot and its mask after selecting the checkpoint.
model.load_state_dict(best_state)
with no_grad():
    pred = model(test_data.x, test_data.edge_index).squeeze(-1)
    test_r2 = r2_score(test_data.y[test_data.mask], pred[test_data.mask])

print(f"Best validation R²: {best_val_r2:.4f}")
print(f"Test R²: {test_r2:.4f}")

Evaluation notes

  • Temporal split (for the TH and THI settings) is not available for city-reviews, city-roads-M, city-roads-L, and web-traffic.
  • THI is selected with split="THI"; there is no separate snapshot constructor argument. Unpack the three returned Data objects as train, validation, and test.
  • Use each THI graph’s mask to obtain nodes used at the corresponding stage.
  • Fit models and learned preprocessing on training data; use validation data for model selection, and reserve test labels for final evaluation.
  • By default, PyG converts directed graphs to undirected graphs. Set to_undirected=False explicitly when your experiment requires the original directionality, and report this choice.
