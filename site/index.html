GraphLand

A Benchmark of Real-World Industrial Datasets for Graph Machine Learning

GraphLand is a benchmark for graph machine learning focused on node property prediction. Its 14 datasets span real-world industrial domains, with diverse graph sizes, structures, and prediction tasks.

Node features are tabular: mixtures of numerical and categorical fields with different meanings and distributions. The datasets cover social networks, the web, commerce, advertising, road networks, and crowdsourcing.

Four standardized evaluation settings support reproducible comparisons. RL uses a 10% / 10% / 80% random train / validation / test split; RH uses 50% / 25% / 25%. TH uses a 50% / 25% / 25% temporal split. THI uses the same temporal split with three graph snapshots for inductive training, validation, and testing.
